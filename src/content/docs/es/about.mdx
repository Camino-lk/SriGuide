Si alguna vez has intentado buscar información para un viaje a Sri Lanka, quizá conozcas el problema: la información está ahí fuera,
repartida entre blogs de agencias de viajes, vlogs de YouTube, hilos de Reddit y páginas web del Gobierno.
Pero organizarlo todo para que resulte realmente útil lleva horas. Y gran parte de lo que encuentras al principio no está ahí para ayudarte.
Está ahí para posicionarse en los motores de búsqueda (como Google).

Las páginas web de las agencias de viajes suelen publicar contenido sobre destinos no porque sea la mejor guía, sino porque atrae tráfico de búsqueda.
**Hay casos aún peores**: existen sitios web de terceros que se hacen pasar por servicios oficiales, cobran por cosas que son gratuitas
y son tan convincentes que hay que rebuscar entre páginas ocultas para descubrir que no son el servicio oficial. (Por ejemplo: sitios web sobre el proceso de solicitud de ETA)

Esta página web es un intento de hacer algo diferente. Una guía gratuita, independiente, escrita para los queridos viajeros.

## Quiénes somos

Proyecto de código abierto iniciada por `Camino`, una fundación de startups en línea centrada en el sector turístico de Sri Lanka.

**Camino**: Open Roads, Shared Journeys - Inspiring meaningful travel experiences.  
GitHub Organization: https://github.com/Camino-lk

**Developers**:

- Dilshan-H (https://github.com/Dilshan-H)

**Tech Stack**:

Creado con [Astro Starlight](https://starlight.astro.build/), que incorpora funciones de localización i18n y temas.
Funcionalidades de aplicación web progresiva (PWA) diseñadas con `vite-pwa`.

**Objetivo principal**:

Ofrecer a los visitantes de Sri Lanka un recurso fiable, honesto y de libre acceso.
Información práctica sobre cómo desplazarse, mantenerse seguro, conocer las costumbres locales, encontrar buena comida
y planificar un viaje que realmente funcione, sin tener que consultar varias fuentes y preguntarse en cuáles confiar.

## Lo que recomendamos aquí

Las aplicaciones, los servicios y los operadores mencionados en esta web tienen que pasar por un
proceso básico de selección antes de aparecer en la lista. No hay anuncios pagados,
ni acuerdos de afiliación: si aparece aquí, es porque ha superado los requisitos por méritos propios.

[Consulta nuestros criterios de inclusión →](/es/vetting-criteria)

---

## Qué NO es

- **No es una agencia de viajes.** No hay reservas, ni comisiones, ni hoteles ni operadores turísticos asociados.
- **Sin publicidad.** Sin banners, sin contenido patrocinado, sin anuncios pagados.
- **Sin acceso restringido.** Todo el contenido de esta página web es gratuito, de forma permanente.
- **Aún no está terminado.** Este es un proyecto en constante evolución. Se añaden y mejoran páginas con regularidad. Si te encuentras con algo incompleto, es porque está en proceso de elaboración, no porque se haya abandonado.
