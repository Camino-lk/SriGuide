## GitHub — Errores y solicitudes de nuevas funciones

Si has detectado un problema técnico, un error en el diseño o tienes una idea para mejorar el sitio, GitHub Issues es el mejor lugar para comunicarlo.
Así se mantiene todo organizado y otras personas pueden comprobar si ya se ha informado del problema.

[Abre una incidencia en GitHub →](https://github.com/Camino-lk/SriGuide/issues)

## Qué escribir

¿No estás seguro de si vale la pena enviar tu mensaje? Probablemente sí. Estos son los tipos de mensajes que siempre son bienvenidos:

- Hay algún dato en la web que está desactualizado, es incorrecto o falta
- Tienes información de primera mano sobre un destino, una experiencia o un servicio en Sri Lanka
- Te gustaría aportar contenido o colaborar con la web
- Quieres compartir tus comentarios sobre cómo la web podría ser más útil
- Tienes alguna pregunta sobre Sri Lanka que no has encontrado respuesta en la web

---

## Límites

Los métodos de contacto anteriores no son el canal adecuado para lo siguiente:

- **Consultas sobre patrocinios**: este sitio web no acepta patrocinios ni anuncios pagados
- **Situaciones urgentes o de emergencia**: consulta la [página de emergencias](/es/emergency)
- **Spam, acoso o contenido inapropiado**
